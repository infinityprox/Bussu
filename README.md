# CityLife3D

A mobile-first 3D city sandbox built with Three.js.

## Run

Open `index.html` through a static web server or enable GitHub Pages for the `main` branch. Internet access is required to load Three.js from jsDelivr.

## Controls

- Left joystick: move / steer
- Drag the screen: rotate the camera
- Enter Car: switch between walking and driving
- New Task: choose another exploration marker

This is an early playable prototype. Buildings and roads are procedurally generated; missions are simple exploration tasks.
